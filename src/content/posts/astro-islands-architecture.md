Astro представляет инновационный подход к созданию веб-приложений через архитектуру островов. Вместо отправки всего JavaScript на клиент, Astro позволяет создавать изолированные интерактивные компоненты - "острова" - которые загружаются только когда это необходимо.

## Что такое архитектура островов?

Архитектура островов - это паттерн, при котором большая часть страницы рендерится как статический HTML, а интерактивные компоненты загружаются отдельно. Это значительно улучшает производительность и время загрузки.

## Преимущества подхода

- **Минимальный JavaScript**: Загружается только необходимый код
- **Быстрая загрузка**: Статический HTML отображается мгновенно
- **Гибкость**: Можно комбинировать разные фреймворки
- **SEO**: Полный контент доступен сразу

## Пример использования

```astro
---
import InteractiveCounter from './InteractiveCounter.vue';
---

<div>
  <h1>Статический заголовок</h1>
  <InteractiveCounter client:load />
</div>
```

Директива `client:load` говорит Astro загрузить этот компонент как интерактивный остров.
