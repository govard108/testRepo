Astro и Next.js - два популярных фреймворка для создания веб-приложений. Давайте разберем их отличия и поймем, когда использовать каждый из них.

## Философия

**Next.js** - полнофункциональный React фреймворк для создания динамических приложений. Ориентирован на React экосистему.

**Astro** - content-focused фреймворк с минимальным JavaScript. Поддерживает множество фреймворков и оптимизирован для контентных сайтов.

## Производительность

**Next.js:**
- Отправляет React код на клиент
- Гидратация всего приложения
- Больший размер бандла

**Astro:**
- По умолчанию zero JavaScript
- Частичная гидратация (острова)
- Минимальный размер бандла

## Когда использовать Next.js

- Сложные SPA приложения
- Интерактивные дашборды
- Приложения с real-time обновлениями
- Нужна глубокая интеграция с React

## Когда использовать Astro

- Контентные сайты и блоги
- Документация
- Маркетинговые сайты
- E-commerce каталоги
- Проекты с акцентом на производительность

## Пример кода

**Next.js:**
```jsx
export default function Page() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```

**Astro:**
```astro
---
import Counter from './Counter.vue';
---

<div>
  <h1>Статический контент</h1>
  <Counter client:load />
</div>
```

## Вывод

Оба фреймворка отличные, но решают разные задачи. Next.js - для приложений, Astro - для контента. Выбирайте инструмент под свои потребности.
