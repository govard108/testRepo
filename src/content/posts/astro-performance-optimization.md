Astro из коробки обеспечивает отличную производительность, но есть несколько техник, которые помогут выжать максимум из вашего сайта.

## Оптимизация изображений

Используйте встроенную оптимизацию изображений:

```astro
---
import { Image } from 'astro:assets';
import myImage from '../assets/photo.jpg';
---

<Image src={myImage} alt="Описание" />
```

Astro автоматически оптимизирует изображения, создает WebP версии и генерирует responsive размеры.

## Частичная гидратация

Используйте правильные директивы для загрузки компонентов:

- `client:load` - загрузить сразу
- `client:idle` - загрузить когда браузер свободен
- `client:visible` - загрузить при появлении в viewport
- `client:media` - загрузить при совпадении медиа-запроса

## Prefetch ссылок

Включите автоматический prefetch для ускорения навигации:

```js
export default defineConfig({
  prefetch: {
    prefetchAll: true
  }
});
```

## Минимизация бандла

- Используйте динамические импорты
- Избегайте больших библиотек на клиенте
- Проверяйте размер бандла с помощью `astro build --analyze`

Следуя этим практикам, вы сможете достичь идеальных показателей в Lighthouse.
